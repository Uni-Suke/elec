## まず直感で：差をならすか、大小を決めるか
オペアンプは負帰還をかけ、入力の差が小さくなるよう出力を調整して増幅します。コンパレータは2つの入力の大小を判定し、出力を切り替えます。

## オペアンプの原理と記号
三角形の＋入力（非反転）、−入力（反転）、出力、電源端子があります。開ループでは非常に大きい差動利得を持ち、負帰還をかけて使います。「＋と−が同じ電圧になる」は、負帰還が働き、出力も入力も正常範囲内にあるときの近似です。

非反転増幅なら Av = 1 + Rf/Rg。10 kΩと20 kΩなら3倍。ただしオペアンプは電源より大きな出力を無制限に作れません。バッファ、センサー増幅、フィルタに使います。

| データシートの欄 | 選ぶための問い |
| --- | --- |
| 推奨電源電圧 | 3.3 V単電源で動くか |
| 入力同相範囲 | 入力0 V〜1 Vが含まれるか |
| 出力スイングと負荷 | 必要な3.0 Vまで、指定負荷で届くか |
| GBW・スルーレート | ゲインと周波数に余裕があるか |
| 入力オフセット・バイアス電流 | 微小信号へどれだけ誤差が乗るか |
| 安定性・容量負荷 | ユニティゲインやADC入力を安定駆動できるか |

「レール・ツー・レール」でも、どちらの端子が対象か、負荷条件は何か確認します。誤配線、過電圧、出力短絡、容量負荷での発振が原因で発熱や出力張り付きが起こります。

## コンパレータ
記号は似ていますが出力方式が重要です。オープンコレクタ／オープンドレインなら外付けプルアップが必要で、プッシュプルなら通常不要です。入力差が小さいところでノイズにより何度も反転するため、ヒステリシスを付けることがあります。

入力範囲、伝搬遅延、出力方式、入力オフセット、ヒステリシス、許容差動電圧を確認します。電源監視、しきい値検出、ゼロクロス検出が典型用途です。遅いオペアンプを飽和させて比較器代わりにすると、復帰が遅い、位相反転するなどの問題があり、適合性を確認せず置き換えません。

## テスターとオシロで確認
まず電源端子、次に両入力、最後に出力を測ります。増幅器なら入力×ゲインが出力範囲に収まるか計算します。出力がレール付近に張り付く場合、入力範囲、帰還の向き、断線を疑います。テスターで中間電圧でも、高速発振の平均かもしれないのでオシロも使います。
