## まず直感で：すぐ近くの小さな蓄え
コンデンサは電圧が急変しようとすると電流を出し入れします。電源が遠いときの瞬間的な不足を近くで補ったり、抵抗と組み合わせて急な変化を丸めたりします。

## 原理と回路記号
絶縁体を挟む電極に電荷を蓄え、Q = CV。電流は i = C × dv/dt です。「DCを通さない」は充電後の理想的な定常状態の話で、充電中は電流が流れます。記号は平行な2本の線、極性付きでは＋表記や曲線の極板も使われます。

容量の単位はF。100 nF = 0.1 µF、1 µF = 1,000 nFです。蓄積エネルギーは½CV²。短絡で放電せず、所定の抵抗を使います。

## 電解コンデンサ
大きい容量を比較的小さく実現でき、電源の平滑や低周波のエネルギー補助に使います。一般的なアルミ電解は極性があり、本体の帯は通常マイナス側ですが製品の表示規則を確認します。逆接や耐圧超過は発熱・ガス発生・破裂の原因です。

| データシート項目 | 選定・故障との関係 |
| --- | --- |
| 静電容量、許容差 | 100 µF ±20%など。時定数の精密設定には不向きな場合 |
| 定格電圧 | 最大DC電圧と重畳リプルに余裕を持たせる |
| ESR、許容リプル電流 | 内部発熱はリプル電流とESRに依存 |
| 寿命・温度条件 | 高温で寿命が縮む。単純な年数保証ではない |
| 漏れ電流 | 高抵抗回路の電圧をずらすことがある |

乾燥や劣化で容量が減りESRが増えると、電源リプルが増えたり起動不良になります。膨らみは故障の手掛かりですが、膨らまない故障もあります。

## セラミックコンデンサ
小型で高周波特性がよく、ICのデカップリングに使います。通常は無極性。C0G/NP0は温度・電圧依存が小さく、X7R等は容量を大きくしやすい一方、DCバイアスで実効容量が減ります。

| データシート項目 | 選定・故障との関係 |
| --- | --- |
| 誘電体分類 | 信号フィルタは安定性、電源補助は容量と特性を比較 |
| DCバイアス特性 | 「10 µF」と書かれても使用電圧で10 µFとは限らない |
| 温度特性・容量許容差 | 最小実効容量で安定動作するか確認 |
| ケース寸法・実装条件 | 基板曲げのクラックで短絡することがある |

## なぜICの電源ピン近くに置くのか
配線にはインダクタンスがあるため、遠くの電源は急な電流変化へ瞬時に応答できません。ICのVCCとGNDのすぐ近くにコンデンサを置き、往復経路を小さくします。100 nFはよくある出発点ですが、推奨回路、電流変動、周波数で決めます。大容量1個だけでは高周波の補助を置き換えられません。

## 測定でわかること・わからないこと
無通電で放電を確認して測ります。抵抗レンジでずっと低抵抗なら短絡を疑いますが、充電で表示が変わるため単純な良否判定はできません。容量レンジで容量、LCR/ESR計で条件付き特性を調べます。テスターだけでは動作電圧での漏れや高周波性能を保証できません。
