## まず直感で：ゲート電圧で通り道を開く
一般的なエンハンスメント型MOSFETは、ゲートとソースの間に適切な電圧を加えると電流が流れやすくなります。ゲートは絶縁されているためDC入力電流は小さいですが、コンデンサのように電荷を出し入れして動かします。

## N-channelとP-channel
N-channelを低側に置くならSをGND、Dを負荷の下側に接続します。ONには正のVGS。P-channelを高側に置くならSを正電源側とし、ONには負のVGSを与えます。制御するのはGNDからのVGではなく、**VGS = VG − VS**です。

回路記号はGとチャネルの間に隙間があります。ディスクリートMOSFETのボディダイオードはN型でSからDへ順方向。OFFでも逆方向を常に遮断できるわけではありません。DとSを入れ替えてよいとは考えません。

## しきい値と十分なONは違う
VGS(th)は小さい規定電流が流れ始める条件です。負荷電流を流して低損失になるゲート電圧ではありません。3.3 V GPIOなら、2.5 Vや3.0 V等の実駆動以下の条件でRDS(on)の最大値が規定された品種を検討します。典型グラフだけでは最悪値の保証になりません。

| データシート項目 | 確認すること |
| --- | --- |
| VDS、VGS絶対最大 | 電源・サージとゲートの最大差電圧 |
| RDS(on)最大値とVGS | 実際に与えられる電圧で低抵抗か |
| Qg、Qgd | ゲート駆動の充放電電流と切替時間 |
| SOA、熱抵抗 | 線形動作や立上り時を含め熱的に安全か |
| IDの条件 | ケース温度などの前提。表紙の大電流をそのまま使わない |

RDS(on) = 0.1 Ω、0.2 Aなら導通損失4 mW。ただし温度で抵抗が増え、PWMでは切替損失も加わります。ゲート直列抵抗はリンギングと電流を抑え、G-S間のプルダウンは起動時の浮遊を防ぎます。

## JFET：接合で通路を絞る
JFETはゲートのPN接合の逆バイアスでチャネルを狭めます。一般的なN-channel JFETはVGS = 0で流れ、負のVGSで絞るデプレッション型です。一般的なエンハンスメントMOSFETのような「0 VでOFF」とは違います。

記号はチャネルへ接合ゲートの矢印が付く形。IDSS、VGS(off)、ゲート漏れ、雑音、耐圧を確認し、高入力インピーダンスの信号増幅などに使います。特性ばらつきが大きいので自己バイアスなどで動作点を安定させます。

## 壊れ方と確認
静電気、VGS超過、VDSサージ、過熱でゲート破壊やD-S短絡が起きます。無通電でG-Sを適切に放電し、D-Sのボディダイオードや短絡を確認します。ゲート電荷が残るとONして良否を誤判定します。単体で良く見えても、高温時の損失や動作耐圧は別途評価が必要です。
