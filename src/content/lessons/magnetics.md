## まず直感で：電流の変化にブレーキをかける
インダクタは「流れ続けようとする」性質を持ちます。急にスイッチを切ると、電流を続けるために高い電圧が生じます。リレーのコイルへダイオードを付ける理由です。

## インダクタの原理・記号・使い方
巻線や磁性体に磁界を作り、v = L × di/dt。単位はH、µH、mH。図ではコイル状の線とL番号で表します。蓄積エネルギーは½LI²。DC-DCコンバータ、フィルタ、電流の平滑に使います。

| 仕様・データシート欄 | 選び方 |
| --- | --- |
| インダクタンスと許容差 | スイッチング周波数とリプル電流から決める |
| 飽和電流 Isat | ピーク電流でLが急低下しないこと。定義条件に注意 |
| 温度上昇電流 Irms | 巻線発熱を許容するか。Isatとは別 |
| 直流抵抗 DCR | I²Rの銅損と電圧降下 |
| 自己共振・コア損 | 使用周波数での特性と発熱 |

過電流で飽和すると電流が急増し、スイッチ素子も壊れます。巻線の過熱は断線や絶縁破壊を招きます。テスターの導通で断線は見つけられても、巻線間の小さな短絡やインダクタンス低下はLCR計等が必要です。

## トランスの原理・記号・使い方
2つ以上の巻線を磁気的に結合した部品。記号は向かい合うコイル、コア線、極性を示すドットです。理想的には V2/V1 = N2/N1。たとえば巻数比2:1なら入力の交流振幅の約半分が二次側に現れます。

トランスはDC電圧をそのまま変換しません。一次側へDCを直接加えると磁気飽和と巻線抵抗で大電流になり得ます。パルス／交流と、磁束を戻す設計が必要です。絶縁電源や信号絶縁に使いますが、絶縁のあるトランスと単巻トランスは違います。

| 仕様・データシート欄 | 選び方 |
| --- | --- |
| 巻数比・ドット・ピン配置 | 電圧比と信号の位相を確認 |
| 定格VA・使用周波数 | 発熱と磁束密度を制限 |
| 絶縁耐圧・沿面距離 | 用途に必要な絶縁区分を満たすか |
| 漏れインダクタンス | スイッチング時の電圧スパイクに影響 |

断線は抵抗測定で確認できますが、テスターで「導通なし」でも安全な絶縁を証明できません。本教材では商用ACトランスの配線実験は行いません。
