## まず直感で：アナログを数字に、数字をアナログに
ADCは電圧等を数値へ変換し、DACは数値に応じた電圧や電流を出します。ロジックICは0と1として解釈する信号を演算します。いずれも電源とGND、適切な信号範囲が必要です。

## ADC（A/Dコンバータ）
記号はAIN、VREF、電源、デジタル出力等を持つブロック。Nビットなら2^N個のコードを使います。理想的な3.3 V範囲の12 bit ADCなら1 LSB ≈ 3.3/4096 = 0.806 mV。ただし実際のコード端点や伝達関数はデータシートに従います。

| データシート欄 | 設計に使う理由 |
| --- | --- |
| 入力範囲・絶対最大 | 3.3 V電源だから0〜3.3 V入力とは限らない |
| 基準電圧・精度 | 全スケールとスケール誤差を決める |
| 分解能・INL・DNL・ENOB | ビット数と実際の有効精度は違う |
| サンプル時間・信号源抵抗 | 内部サンプル容量を十分に充電できるか |
| サンプルレート・帯域 | エイリアシングを防ぐ前段フィルタを考える |

ESP32などは型番・減衰設定・校正により範囲が違います。「12 bitだから正確に0.806 mVを測れる」とは限りません。テスターで入力を確認し、複数の既知電圧でコードを記録して校正と飽和を確認します。

## DAC（D/Aコンバータ）
デジタルコードを抵抗網や電流源などで変換します。記号はDATA、VREF、VOUT等のブロック。分解能、出力範囲、セトリング時間、グリッチ、出力駆動能力、基準精度を見ます。DAC出力へ直接モータや低抵抗負荷をつながず、必要ならバッファを入れます。

PWMをローパスで平均化してアナログに近い電圧を得る方法もありますが、リプル、応答速度、負荷依存があり、独立したDACと同じ特性ではありません。テスターでDC値、オシロで変化時の波形とリプルを確認します。

## ロジックIC
AND、OR、NOT、NAND、フリップフロップなど。記号はゲート形や機能ラベル付きブロック。論理が同じでもHC、HCT、LVCなどのファミリで電源・入力しきい値・許容入力が違います。

VIH（Hと保証される最小入力）、VIL（Lと保証される最大入力）、VOH/VOL（規定電流での出力）、伝搬遅延、入力リーク、電源OFF時の許容条件を確認します。CMOS入力を浮かせると不定動作や余分な電流が生じるので、未使用入力も適切に固定します。

## よくある故障と確認
ADC入力の過電圧は保護素子へ電流を流し、ピンや電源系を傷めます。ロジック出力同士を反対レベルで接続すると競合して発熱します。まず電源と基準電圧、次に入力値、通信と出力の順で調べます。導通だけで機能の正常性は保証できません。
