# 情報設計と実装計画

## 調査結果
Astro 7.3.3 / TypeScript strict / npm。初期テンプレートのみ。既存機能・ユーザーコンテンツなし。静的生成を継続し、UIフレームワークは追加しない。

## 学習設計
安全を全章の前提とする。基礎→部品→基本回路→計測→8段階の実験→故障診断→設計手順と8演習。章を横断する関連記事と目的別の入口も設ける。説明は直感→技術→数値例→測定／故障の順。設計例は折りたたみ、読者が先に要求仕様から考えられるようにする。

## 情報構造
- `/`: 目的別入口、学習章、代表教材、実験
- `/roadmap/`: 順序、前提、到達目標
- `/category/[category]/`: 章ごとの教材一覧
- `/learn/[id]/`: 教材、図解、目次、問題、前後・関連リンク
- `/search/`: 本文・用語を含むローカル検索
- `/about/`: 学び方、安全、技術レビュー方針
- Markdown + frontmatterをAstro Content Collectionsで検証

## 視覚設計
実験ノートのような白地、深いグリーンと細い罫線。左の固定カリキュラム、広い本文、教育に使う自作回路図。スマホではナビゲーションを開閉する。装飾写真やアニメーションは使わない。

## 手順
1. 共有レイアウトと代表的なトップを実装し、プレビュー起動。
2. 教材・SVG・共通教育コンポーネント・静的ルートを実装。
3. 検索・テーマ・スマホナビを接続。
4. 一次資料と照合し数式・定格・極性・GND・測定接続をレビュー。
5. ビルド、型、全内部リンク、主要ページとレスポンシブ表示を確認。
6. READMEとレビュー記録・残作業を整理。
